# contacts

An Expo (React Native) exercise that reads the phone's contacts. Tap Get Contacts, allow access, and it lists each contact's name and first phone number (N/A if there is none).

Stack: Expo SDK 49, React Native 0.72, `expo-contacts`.

Run:

```bash
npm install
npm start
```

Then open it in Expo Go, or use `npm run android` / `npm run ios`. The Expo Go app in the stores only runs the newest SDK, so on a phone it needs an upgrade from SDK 49 first.

Status: course exercise, October 2023 (two commits, 11 Oct 2023).
